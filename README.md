Double Love 为场记元数据提供自动化标准化处理。支持离线使用。通过批量处理、本地化处理，实现与 Adobe Premiere、Silverstack、DTG Slate 工作流的衔接，帮助保持元数据一致性。

## ✨ 功能特性

- 🎬 影视工业化流程支持
- 📝 智能元数据规范化处理
- ⚡ 零延迟本地化处理
- 🧩 无缝对接 Adobe Premiere

## 🚀 快速入门

### 基础工作流

1. 场记记录：使用 DTG Slate 生成交互式场记单
2. 数据管理：通过 Silverstack Lab 导入场记数据
3. 文件导出：生成 Adobe Premiere Pro XML
4. 标准化处理：使用 Double Love 进行智能优化

示例：
- 输入xml：`UnitA_304_20250127.xml`
- 输出xml：`UnitA_304_20250127_Double_LOVE.xml`

### 详细示例

#### 文件命名优化
- 程序会自动处理场景号、镜头号和场次号的格式
- 自动为数字补充前导零
- 自动处理大小写规范
- 自动清理多余的下划线

#### 片段命名规则

处理后的片段名遵循以下动态格式：

#### 不同数据源的命名格式

1. **有Season+Episode数据时**（CSV中包含Season和Episode列）：
```
{season}_{episode}_{scene}_{shot}_{take}{camera}_{rating}
```

2. **仅有Episode数据时**（CSV中仅包含Episode列）：
```
{episode}_{scene}_{shot}_{take}{camera}_{rating}
```

3. **无CSV数据时**（传统格式）：
```
{scene}_{shot}_{take}{camera}_{rating}
```

#### 参数说明

| 参数 | 说明 | 格式 | 来源 | 示例 |
|------|------|------|------|------|
| `season` | 季数号 | 2位数字 | CSV文件Season列 | 01 |
| `episode` | 集数号 | 2位数字 | CSV文件Episode列 | 44 |
| `scene` | 场景号 | 3位数字 | 文件名解析 | 026 |
| `shot` | 镜头号 | 2位数字 | 文件名解析 | 04 |
| `take` | 拍摄次数/条数 | 2位数字 | 文件名解析 | 01 |
| `camera` | 摄影机标识 | 小写字母 | 文件名解析 | d |
| `rating` | 拍摄评级 | 字符串 | XML标签Label解析 | ok/kp/ng |

**评级映射规则**：
- `Circle` → `ok`（圈选/通过）
- `KEEP` → `kp`（保留）
- `NG` → `ng`（不合格）
- 其他标签转换为小写
- "No Label" 不提取评级

**格式说明**：
- `{take}{camera}` 在命名中连写（如：01d）
- 所有数字参数自动补零到指定位数
- CSV 文件需包含 `Name` 列，并可包含 `Season`、`Episode` 或两者；Season/Episode 只接受 1～99
- `Name` 匹配会忽略路径、常见媒体扩展名和大小写；CSV 支持 BOM、CRLF、引号、字段内逗号和转义引号

#### DIT 信息
- 自动添加 DIT 信息：'Generated by https://double-love.ahua.space'
- 如果需要去除请自行部署😁😁

#### 命名示例

1. **有Season + Episode CSV数据时**：
   - 输入文件：`D_0039C001_240808_050950_a1D0U`（季数：1，集数：44）
   - 输出文件：`01_44_026_04_01d`

2. **仅有Episode CSV数据时**：
   - 输入文件：`D_0039C001_240808_050950_a1D0U`（集数：44）
   - 输出文件：`44_026_04_01d`

3. **无CSV数据时（传统格式）**：
   - 输入文件：`D_0039C001_240808_050950_a1D0U`
   - 输出文件：`026_04_01d`

#### 序列分辨率设置示例

1. FHD 分辨率（默认）：
   - 宽度：1920
   - 高度：1080   
2. DCI 2K 分辨率（自定义）：
   - 宽度：2048
   - 高度：1080   

#### 批量处理示例

1. 同时上传多个 XML 文件和至多一个 CSV 文件（XML 与 CSV 合计最多 99 个已接受文件）：
   ```
   UnitA_304_20250123.xml
   UnitA_305_20250124.xml
   UnitA_306_20250125.xml
   ```

2. 处理完成后将得到：
   ```
   UnitA_304_20250123_Double_LOVE.xml
   UnitA_305_20250124_Double_LOVE.xml
   UnitA_306_20250125_Double_LOVE.xml
   ```

## 📦 安装与使用

1. 克隆项目

```bash
git clone https://github.com/Ahua9527/Double-Love.git
cd Double-Love
```

2. 安装依赖

```bash
pnpm install
```

3. 本地开发

```bash
pnpm dev
```

4. 构建项目

```bash
pnpm build
```

5. 运行 Web 维护版检查

```bash
pnpm lint
pnpm test
git diff --check
```

## 🔒 安全说明

- 所有文件处理均在浏览器本地进行，不会上传到服务器
- XML 最大 50MB，CSV 最大 10MB；CSV 只用于可选的 Season/Episode 辅助命名
- 当前只接受一个 CSV，XML 与 CSV 合计最多接受 99 个文件；重复文件会被忽略
- `public/_headers` 为当前 Cloudflare Pages 静态部署声明 CSP、防嵌入和最小权限响应头；上线后仍需检查真实响应
