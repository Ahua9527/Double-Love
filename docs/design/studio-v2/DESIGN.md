# Double Love Studio v2 · 视觉关键屏

这组关键屏是下一版产品壳的视觉基线：本地优先、亮色为先、安静而有工作感。它参考了 macOS 应用常见的信息层级与 BaoCut 的密度控制，但没有复用 BaoCut 的品牌、图标、文案、素材或界面结构。

## 视觉方向

- **气质**：像一件可靠的本地工具，而不是营销页。页面留白充足，信息密度集中在真正需要做决定的位置。
- **字体**：优先使用系统字体：`-apple-system`、`SF Pro Text/Display`、`PingFang SC`。时间码、模型 revision、帧率等使用 `SF Mono`，让数字可以快速扫读。
- **颜色**：背景使用温和的冷暖中性灰（`#f4f4f1`、`#fbfbfa`、`#ffffff`），正文使用炭黑（`#23262c`），次要文字使用灰（`#6f737b`）。功能蓝只承担选中、链接和主要操作（`#4a63c7`），不用于大面积背景。
- **结构**：边框为 1px、圆角 5–8px；卡片只在表达层级时出现。阴影几乎不可见，避免浮夸的“网页卡片”感。没有渐变、霓虹、Sparkle 或装饰性插画。
- **图标**：使用统一 1.5px 描边的几何图标，尺寸以 15–16px 为主。图标优先表达动作或状态，不把图标当装饰。
- **动效约束**：实现时只允许短暂的 opacity/transform 过渡（约 160–220ms）；支持 `prefers-reduced-motion`，不使用会触发布局重排的动画。

## 关键屏说明

### `welcome-1440x900.png`

首次启动的三步可跳过引导。左侧是明确的 1/3、2/3、3/3 步进，不抢主内容；主区域说明本地处理边界，并用一个轻量的窗口示意表达“素材留在 Mac 上”。底部同时提供“稍后再做”和“继续”，让用户能立即进入项目，也能回到设置再次查看。

### `library-1440x900.png`

项目库采用“一个主项目 + 轻量列表”的层级，而不是三个等宽营销卡片。主项目显示媒体数量、转录片段、输出时长和帧率；次级项目使用行式列表，能快速扫读。未安装模型只在底部显示低干扰提示，项目管理与模型安装不互相阻塞。

### `editor-1440x900.png`

编辑器保持“视频左、文本右、时间线下”的工作结构。预览区域使用中性几何占位画面，重点示范字幕位置、时间码和当前片段；右侧转录以说话人、时间码和 active segment 分层；时间线使用轻量的色块轨道和单一蓝色播放头。

### `settings-general-760x580.png`

设置独立窗口：标题栏居中、左侧七页导航、右侧紧凑行式设置。通用页把启动、编辑和界面分组；每一行都说明设置影响，开关和选择框保持原生控件比例，不做大卡片堆叠。

### `settings-models-760x580.png`

模型页只呈现真实支持的组件：Qwen3 ASR 0.6B/1.7B、Forced Aligner 0.6B、Silero VAD + WeSpeaker。顶部给出按设备内存的推荐配置；模型行明确显示 revision、体积、安装状态和动作；Forced Aligner 的“不可移除”状态表达依赖保护；底部始终能看到模型目录。

## 实现时的不可变约束

1. 全局设置与项目设置要分开：字幕默认值只影响新项目，应用到当前项目必须是显式操作。
2. 模型状态必须能表达 `not_installed / queued / downloading / paused / verifying / installed / corrupt / failed`，截图中的“已安装”“未安装”不能只是静态标签。
3. 任何下载或校验失败都不能显示为已安装；模型目录切换、校验、原子安装要先成功再切换路径。
4. 亮色是首要验收模式；暗色、键盘焦点、VoiceOver、中文输入法和减少动效需要沿用同一套层级与 token。
5. 本地处理边界需要在引导、模型页、隐私页和缺模型提示中保持同一套说法：不默认上传音频或声纹，原始媒体不复制。

## 标注

PNG 由本地静态高保真画板按目标窗口尺寸渲染，并用图像尺寸检查确认：欢迎页、项目库、编辑器为 1440×900；通用设置和本地模型为 760×580。画板只用于视觉确认，不是产品运行时实现。

稿件中的项目名称、路径、媒体数量、模型体积、内存需求和 revision 均为合成展示数据，不是实现常量。正式界面必须从项目状态、设备检测和经过 SHA-256 校验的模型清单读取真实值。
